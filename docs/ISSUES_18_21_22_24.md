# Issues 18, 21, 22, and 24

- The backend event cache is persisted at `EVENT_STORE_PATH` (default: `data/events.json`) and writes atomically. Set the path to a mounted persistent volume on Render.
- Keeper-relevant Soroban events use topics `released`, `cancelled`, `claimed`, `completed`, and `swap` with the record ID as the second topic.
- All contracts now publish name, version, and description metadata. Existing deployments need to be redeployed for metadata to appear on-chain.
- Run `scripts/generate-contract-specs.sh` after installing the Stellar CLI to regenerate ABI spec JSON files.
